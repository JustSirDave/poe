How should I read this?

This view reports token fields already present in local session logs. Input processed includes uncached input, cache reads, and cache creation when the agent reports them. Agentic tool loops can process the same cached context many times, so the number can be much larger than the text you typed. Missing fields remain unknown, and these totals are workflow signals rather than a bill. Opening and refreshing this dashboard does not call a model or consume assistant tokens.

Scan details and limitations

Poe can inspect reasoning text or summaries recorded in session logs. Hidden, encrypted, or unrecorded thinking remains unavailable, and Poe cannot verify that a task succeeded.
